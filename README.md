# ⚡ VUCX — 3D Unit Converter

> A desktop unit conversion utility featuring an interactive 3D WebGL particle field built with **Three.js** and packaged for Windows.

## 📥 Download & Run (Windows)

No installation or environment setup is required. The pre-built portable version is packaged in an archive in the **Releases** tab:

1. **[Download Latest Archive (.zip)](../../releases/latest)** *(or check the [Releases](../../releases) tab)*
2. Unpack the downloaded `.zip` archive.
3. Run `unit-converter.exe` (or the launcher in the folder) directly.

---

## ✨ Features

- **🔄 Two-Way Conversions:** Instantly reverse the calculation direction with a single toggle button.
- **📏 Supported Units:**
  - **Distance / Length:**
    - Miles ⇄ Kilometers
    - Meters ⇄ Centimeters
  - **Digital Data Storage:**
    - Bytes ⇄ Kilobytes
    - Megabytes ⇄ Bytes
- **🌌 Interactive 3D Background:**
  - 6,400-point WebGL particle grid simulated in real time with **Three.js**.
  - Dynamic surface deformation tracking mouse/cursor position and touch gestures.
  - Interactive shockwave ripple effects on click/tap.
- **🖥️ Standalone Portable:** Runs offline without installing browsers or additional runtime dependencies.
